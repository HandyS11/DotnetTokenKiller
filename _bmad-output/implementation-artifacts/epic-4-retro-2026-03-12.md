## Significant Discovery: Integration Testing Gap

During retrospective discussion, HandyS11 identified that no real end-to-end integration tests exist against the actual `dtk` binary running real `dotnet` commands. The `DotnetTokenKiller.Cli.IntegrationTests` project exists but has minimal coverage.

**Impact on Epic 5+:** Synthetic fixtures may diverge from real output over time. Real DI wiring, process execution, and CLI argument forwarding are never validated end-to-end.

**Recommendation:** Plan a dedicated Integration Testing Epic between Epic 6 and Epic 7 (before Global Tool packaging). This is too large for a single story addition to an existing epic.
