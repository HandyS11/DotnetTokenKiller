DESCRIPTION:
Run dotnet pack with filtered output

USAGE:
    dtk dotnet pack [args] [OPTIONS]

EXAMPLES:
    dtk dotnet pack
    dtk dotnet pack -o artifacts

ARGUMENTS:
    [args]    Arguments to forward to the underlying dotnet process

OPTIONS:
                           DEFAULT                                                                  
    -h, --help                        Prints help information                                       
    -v, --verbose                     Echo the resolved command line before running                 
        --vv                          Also dump the raw dotnet output and elapsed time              
        --show-log                    Print the path to the full log file when the output was saved 
    -q, --quiet                       Suppress all DTK meta-output; forward only the filtered       
                                      content                                                       
        --tee <PATH>                  Also write the raw output to PATH                             
        --max-lines <N>    0          Print at most N lines of filtered output (0: no limit)
